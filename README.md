# 抖音作者主页字幕批量提取

一个面向 macOS 的本地工具：批量获取抖音作者主页视频，使用 Whisper 将视频口播转写为字幕，并按作者导出 Excel。

## 主要功能

- 支持输入多个抖音作者主页链接，批量处理视频；
- 自动下载视频、提取音频并进行本地语音转写；
- 按作者生成独立 Excel，包含发布时间、视频标题、字幕和视频链接；
- 支持断点续跑，已成功处理的视频会自动跳过；
- 提供本机网页界面，可选择输出目录、Whisper 模型和语言。

仅处理你有权下载、转写和使用的公开内容。请遵守抖音服务条款、版权规则和访问频率限制，不要用于绕过登录、付费或其他访问控制。

## 快速开始（macOS）

在「终端」中运行：

```bash
cd ~/Desktop/AI/抖音作者字幕提取
./安装全部组件.command
./启动程序.command
```

安装器会依次安装主项目依赖、扫码浏览器组件和主页采集器环境。若安装器提示无法访问 `pypi.org` 或 `files.pythonhosted.org`，请先检查网络、DNS 或代理，再重新运行；这不是项目代码或 Python 版本冲突。`ffmpeg` 是音频转换所必需的：如果尚未安装，请先安装 Homebrew 后执行 `brew install ffmpeg`。

## 图形界面使用

- 双击启动后，程序会自动在浏览器中打开仅本机可访问的操作页面；
- 在“作者主页链接”中粘贴链接，一行一个；
- 选择输出目录、Whisper 模型与语言；中文普通话建议选择 `zh`；
- 点击“开始执行”。Excel、日志、音频和状态文件都会保存在所选输出目录中；
- 重复运行同一输出目录会跳过已经成功处理的视频，适合失败后续跑。

## Cookie 与常见情况

作者主页采集由 vendor/TikTokDownloader 的独立进程完成。它可能需要有效的抖音参数配置，且其上游项目明确提示部分加密参数已经过期；请遵守其许可证和平台规则。Cookie 不会写入 Excel 或日志。

若某个主页或视频下载失败，程序不会中断其他任务，会在 `运行报告.json` 中记录原因。建议少量账号先试跑，并降低并发数。

## 目录说明

- `web_app.py`：本机网页操作界面
- `src/`：下载、转写、导出和任务编排逻辑
- `outputs/`：默认生成位置（首次运行自动创建）
- `requirements.txt`：Python 依赖

## 依赖与模型

默认使用 `small` 模型，首次转写会下载模型文件；CPU 环境建议先用 `base` 验证流程，追求中文准确度可用 `medium`。GPU 环境可在界面开启 GPU；若环境不支持会自动回退为 CPU。

## 从源码安装

本仓库不包含虚拟环境、Cookie、下载内容或运行日志。macOS 可双击 `安装全部组件.command` 安装依赖，再双击 `启动程序.command` 启动。

也可在终端中手动创建 Python 虚拟环境并执行：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python web_app.py
```

主页采集器位于 `vendor/TikTokDownloader/`，其运行依赖需按 `安装全部组件.command` 中的步骤另行安装。上游代码保留在仓库中，并附带其原始许可证。
